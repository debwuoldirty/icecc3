# icecc3 (icewm control panel version nueva) 

tuve la idea de traer devuelta el icewm control center para que pudieras hacer todo en entorno grafico sin tener que usar aplicaciones externas todo fue escrito en python3 

#intrucciones de instalacion 

en una terminal cualquiera pega lo siguente parte por parte 

1- git clone https://github.com/debwuoldirty/icecc3.git
2- cd icecc3
3- makepkg -si 

luego de estos pasos ya podrias encontrarlo en tu menu de aplicaciones y en la carpeta "icecc3" proveniente del git encontraras un paquete para llevarlo donde quieras.
